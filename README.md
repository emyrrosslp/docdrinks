# Справочник напитков

Всё, что можно сварить на сервере: состав, время варки, перегонка, выдержка и крепость.

## Оборудование и как им пользоваться

| Что | Из чего | Для чего |
|---|---|---|
| **Котёл** | обычный котёл с водой над огнём (костёр, лава, магма тоже подойдут) | варка, из одного котла получается 3 бутылки |
| **Перегонный куб** | варочная стойка, в верхний слот кладётся 1 светопыль (не расходуется) | перегонка |
| **Малая бочка** | 8 одинаковых деревянных ступенек кольцом 3×3 (середина пустая) + табличка с «Barrel» (или «Бочка») в верхней строке справа внизу | выдержка, 9 слотов |
| **Большая бочка** | 16 ступенек, 18 досок, 4 забора и 1 забор-кран, одна порода дерева, полая внутри + табличка с «Barrel» на кране | выдержка, 27 слотов |
| **Стол запечатывания** | в верстаке: 2 бутылки сверху и 4 доски под ними | запечатывание напитка |

После постройки бочки должно появиться сообщение «Бочка создана». У большой бочки табличку потом можно снять, у малой нельзя, без неё она перестанет работать.

### Варка

1. Поставьте котёл над огнём и налейте воды до краёв.
2. Правым кликом бросайте ингредиенты по одному. Число предметов должно точно совпадать с рецептом.
3. Чтобы узнать, сколько уже варится, кликните по котлу часами.
4. Следите за частицами над котлом: цвет сменяется по мере готовности.
5. Когда время подошло, используйте пустую бутылку правым кликом по котлу.
Васильки и синие орхидеи считаются одним ингредиентом («синие цветы») — для джина подойдёт любой из них.

### Перегонка

1. Поставьте варочную стойку, в верхний слот положите светопыль.
2. В нижние слоты кладите бутылки с варевом из котла.
3. Дождитесь окончания цикла. Время цикла и нужное число проходов указаны в таблицах.

### Выдержка в бочке

1. Откройте бочку: малую правым кликом по табличке, большую по крану.
2. Положите бутылки внутрь. Порода дерева бочки должна подходить рецепту (необходимая указана в таблицах), иначе качество упадёт.
3. Один год выдержки длится 7300 минут, то есть около 5 суток реального времени.
4. Бочку нельзя ломать, пока в ней что-то выдерживается.

### Запечатывание

Запечатанный напиток больше не перегоняется и не выдерживается, в описании не виден процент алкоголя и его можно безопасно хранить в бочках и продавать. Положите бутылку в стол запечатывания.

## Цепочки

Некоторые рецепты используют готовые напитки как ингредиенты. Для пива, вина и браги нужна **закваска**, для виски и джина — **зерновая брага**, для водки и самогона — **картофельная брага**, для ягодного самогона, ликёра и настоек — **ягодная брага**, для морковных напитков — **морковная брага**.

```
Закваска ─┬─► Пшеничное / обычное / тёмное / тыквенное пиво
          ├─► Красное вино ─┬─► Глинтвейн
          │                 └─► Коньяк
          ├─► Зерновая брага ─┬─► Виски
          │                   ├─► Жгучий виски
          │                   └─► Джин
          ├─► Картофельная брага ─┬─► Водка
          │                       ├─► Грибная водка
          │                       ├─► Золотая водка
          │                       └─► Самогон
          ├─► Ягодная брага ─┬─► Ягодный самогон
          │                  ├─► Ягодный ликёр
          │                  └─► Закатная настойка (вместе с морковной брагой)
          └─► Морковная брага ─┬─► Морковный самогон
                               ├─► Золотая морковная настойка
                               └─► Закатная настойка (вместе с ягодной брагой)

Яблочный сидр ─► Яблочный бренди
Кашаса ────────► Пряный ром
```

Количество в составе — это число бутылок готового напитка (для обычных ингредиентов — число предметов).
